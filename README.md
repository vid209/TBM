TANK BRAWL — Мобильная версия
Об игре
TANK BRAWL — это аркадная танковая битва с четырьмя режимами игры. Управляй танком, уничтожай врагов, захватывай флаги и сражайся с друзьями. Игра адаптирована для сенсорных экранов и работает на любых телефонах.

Режимы игры
Офлайн (против ботов)
Сражайся против трёх вражеских танков. После уничтожения всех ботов появляется новая волна. Игра бесконечная.

Захват флага
Забери вражеский флаг (красный квадрат в правом верхнем углу) и доставь его на свою базу (золотой домик в левом нижнем углу). Боты будут пытаться тебя остановить.

PVP 2 игрока (1 ПК)
Играй с другом на одном устройстве. Первый игрок управляется сенсорными кнопками на экране, второй — клавиатурой WASD и X.

По сети
Играй с друзьями через интернет. Для этого нужен запущенный сервер.

Управление
Телефон:
Сенсорные кнопки на экране под игровым полем. Кнопки со стрелками для движения, красная кнопка для выстрела.

ИНСТРУКЦИЯ ДЛЯ ТЕЛЕФОНА
К сожалению, Hamachi не работает на телефонах. Это программа только для Windows, Mac и Linux.

Что делать, если у вас телефон:
Вариант 1 — Играйте на ПК
Установите Hamachi на компьютер, запустите сервер на нём, а телефоном можно управлять через браузер, подключаясь к этому же серверу.

Вариант 3 — Играйте в одной Wi-Fi сети
Если вы в одной комнате или в одной школе/кафе, просто подключитесь к одному Wi-Fi. Тогда в игре вводите реальный локальный IP.

ИНСТРУКЦИЯ ДЛЯ ПК (через Hamachi)
Шаг 1 — Скачать Hamachi
Зайди на hamachi.cc и скачай LogMeIn Hamachi

Шаг 2 — Установить
Установи как обычную программу. Везде нажимай Далее.

Шаг 3 — Создать сеть
Запусти Hamachi. Нажми Создать новую сеть. Придумай название (например TankBrawl) и пароль. Нажми Создать.

Шаг 4 — Подключить друга
Друг устанавливает Hamachi, нажимает Подключиться к существующей сети и вводит твои название и пароль.

Шаг 5 — Узнать IP
В Hamachi у каждого будет свой IP-адрес (типа 25.12.34.56).

Шаг 6 — Запустить игру
Запусти сервер командой node server.js. Открой игру, нажми ПО СЕТИ. Ты вводишь localhost, друг вводит твой Hamachi-IP.

ЧАСТЫЕ ПРОБЛЕМЫ
Друг не видит твой IP — проверь, что он подключился к твоей сети.

Ошибка подключения — отключи брандмауэр Windows на время игры.

Не могу подключиться к серверу — перезапусти Hamachi и попробуй снова.

Телефон не подключается — Hamachi не работает на телефонах. Используй ZeroTier или играйте в одном Wi-Fi.

АЛЬТЕРНАТИВЫ HAMACHI
ZeroTier — работает на телефонах и ПК, бесплатный до 50 устройств. Radmin VPN — только для ПК, очень простой. Ngrok — пробрасывает порт из локальной сети в интернет, не требует установки у друга.

Как играть по сети
Для игры по сети нужен сервер. Инструкция внутри игры при выборе режима По сети.
